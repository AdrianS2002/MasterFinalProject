LSTM Forecast: Renewable Generation vs Demand

Generated by the off-chain DA LSTM model using 7-day weather history. Weather-factor and price-elasticity corrections are applied before the forecast is committed to the contract.

How Day-Ahead Clearing Works

  1. The LSTM engine fetches weather data from Open-Meteo and predicts 24h consumption + renewable generation.
  2. The forecast is committed on-chain via openBidding().
  3. Prosumer nodes submit bids: consumption bid (max WTP) or injection bid (min sell price).
  4. The merit-order algorithm matches supply to demand hour-by-hour and sets the uniform MCP.
  5. Accepted nodes receive a schedule; PSO in Node.sol uses the MCP array as the social guide to converge to the market-optimal plan.

15-Minute Intra-Day MCP & Renewable Forecast

Updated every 15 minutes by the PSO engine. The renewable forecast (green, right axis) is refreshed hourly by the ID LSTM using the latest weather data from Open-Meteo.

How Intra-Day Adjustment Works

  1. Every 15 minutes the PSO engine reads real-time consumption from node contracts and compares to the DA schedule.
  2. Deviations are recorded on-chain via updateInterval().
  3. The ID LSTM re-forecasts the next 4 slots (1 hour) using fresh weather data.
  4. Nodes that deviate from their DA schedule incur an imbalance cost: over-consumption = {{ penaltyPositive }} penalty, under-consumption = {{ penaltyNegative }} rebate.
  5. The imbalance cost feeds back into the PSO objective function in Node.sol, encouraging self-correction in real time.
